# Methodology — Completion Receipt™ #001

## Three comparison views
1. **Traditional delivery** — modeled role-hours for comparable scope and quality using public compensation benchmarks.
2. **AI-assisted delivery without UBuildOS™** — traditional role-hours adjusted only where published productivity studies were reasonably comparable.
3. **UBuildOS™ delivery** — the observed project artifact window and verified project outcome.

## Time
The project has a **66.4-minute observed runtime artifact window**, derived from project timestamps. It is not represented as model compute time, human labor time, or complete active-time telemetry.

## Human-equivalent effort
The traditional comparable scenario is **28–64 hours**, midpoint **44 hours**. It includes project management, marketing/content strategy, public-release and IP/cleanroom design, software/tooling work, QA/recovery, technical documentation, and audit/change control.

## Economics
Traditional replacement-labor scenario: **$2,091–$4,812**, midpoint **$3,291**. This is a modeled replacement-cost scenario, not valuation and not proven savings. Actual project-specific spend was not available, so proven cost avoidance is not calculated.

## AI-assisted comparison
The AI-assisted midpoint is **34.58 hours / approximately $2,534**. The model uses a 25.1% time reduction for applicable knowledge-work tasks from the Harvard/BCG experiment and 55% for applicable coding work from the GitHub Copilot controlled study. No productivity reduction is applied where no sufficiently comparable benchmark was admitted.
